# JavaScript Series - YouTube Tutorials & Source Code

Welcome to the official source code and lecture notes repository for my YouTube JavaScript series! This repository contains clean, well-commented code snippets, practical examples, and notes covering core to advanced JavaScript concepts.

---

## 📂 Repository Structure & Topics Covered

Here is a breakdown of what you will find in this repository:

* **`async await and error handling`**: Learn how to handle asynchronous operations cleanly using `async/await`, `Promises`, `fetch`, and robust `try/catch` error handling blocks.
* **`dom-manipulation`**: Practical examples of selecting elements, modifying styles, creating dynamic elements, and handling user interfaces.
* **`event bubbling capturing delegation`**: Deep dive into the DOM event flow, capturing vs. bubbling phases, and implementing high-performance event delegation.
* **`event handling`**: Comprehensive guides on listening to browser events, mouse movements, keyboard inputs, and form submissions.
* **`eventloop`**: Visualizing and understanding the JavaScript concurrency model, call stack, microtask queue, macrotask queue, and asynchronous execution.
* **`localAndSessionStorage`**: How to store, retrieve, and manage persistent client-side data using Web Storage APIs.
* **`performanceOptimization`**: Techniques to write faster, memory-efficient code including debouncing, throttling, and avoiding memory leaks.
* **`promise-fetch`**: Working with JavaScript Promises (`Promise.all`, `race`, `any`) and making HTTP requests using the Fetch API.
* **`prototypes`**: Understanding prototypal inheritance, constructor functions, and the prototype chain under the hood.
* **`lecture notes`**: Summary notes, cheat sheets, and conceptual breakdowns accompanying the video lessons.
